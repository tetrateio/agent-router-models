*TARS Model Catalog Update*

We are pleased to announce expanded model coverage in TARS. Key updates include:

- *Added:* Anthropic Claude Fable 5.2 costs $8 input and $40 output per million tokens, with a 1,000,000-token context window and 128,000 output tokens. It is also on Google Cloud at the same prices. OpenAI GPT Image 2.6 Sunburst and Flare cost $5 per million text input tokens and $30 per million image output tokens. Google Cloud adds Meta Muse Wonder 1.0 ($4 / $20), Muse Ember 1.0 ($0.10 / $0.50), Muse Spark 1.3 ($1.25 / $4.25), and Gemini Robotics ER 2 Preview ($1 / $5 through December 31, 2026). DeepInfra adds Kimi K3.1 Pro at $1.90 / $9.50. Gemini Embedding 001 returns on the Gemini API at $0.15 per million tokens.
- *Retired:* DeepInfra retired MythoMax L2 13B, Step-5-Preview, Hermes 3 Llama 3.1 405B and 70B, and Meta Llama 3.1 70B Instruct Turbo. xAI retired Grok Imagine Image Quality, and its requests now go to Grok Imagine Image 2.0. Requests to Gemini Embedding 2 Preview now go to Gemini Embedding 2. The Gemini API sends Gemini 3.7 Flash requests to Gemini 3.8 Flash, and Gemini 3.5 Flash requests to Gemini 3.6 Flash. TARS turns both off.
- *Deprecated:* Claude Sonnet 4.5 retires November 30, 2026, on the Claude API and Google Cloud. Use Claude Sonnet 5.5. On the Claude API, fast mode for Claude Opus 4.8 ends November 30, 2026. Use fast mode on Claude Opus 5.5. From December 1, 2026, the Gemini API sends Gemini 2.5 Pro requests to Gemini 3.8 Flash and Gemini 2.5 Flash requests to Gemini 3.5 Flash-Lite. DeepInfra Ling-3.1-flash retires November 15, 2026. Use DeepSeek-V4.1-Flash-1017. GPT Image 1.5, GPT Image 1 Mini, and ChatGPT Image Latest still retire December 1, 2026. Use GPT Image 2.6 Sunburst or Flare.
- *Price changes:* The DeepInfra Hy4 Preview and MiMo-V2.6-Flash promotions ended. Hy4 Preview now costs $0.834 input and $2.501 output, and MiMo-V2.6-Flash costs $0.14 input and $0.28 output. DeepInfra Nemotron 3 Super input fell from $0.085 to $0.075. Claude web search on Google Cloud costs $10 per 1,000 searches for every Claude model. On December 1, 2026, Gemini 4 Argon rises to $4 input and $20 output. The GPT-5.6 Sol promotional price of $4 input and $20 output ends November 30, 2026.
- *Other updates:* The Claude API now accepts Messages requests up to 128 MB, up from 32 MB. Grok 4.7 on Google Cloud is now generally available. Claude models on Google Cloud now list structured outputs, which an organization policy turns off by default. Five DeepInfra DeepSeek models now return up to 393,216 output tokens, and DeepSeek-V3.1 now returns up to 163,840. Claude records now show the 500 MB Files API upload limit. xAI records now show the per-minute rate limits that xAI publishes.

Please move integrations off retired models, and review deprecated models before their retirement dates. Visit the [TARS model catalog](https://router.tetrate.ai/models/) to explore available models and deprecated/retired dates.
