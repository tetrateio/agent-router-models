# Security

## Reporting a problem

Please do not open a public issue for a security problem, such as a credential in this repository or a flaw in its scripts. Use GitHub's private vulnerability reporting: the **Security** tab of this repository, then **Report a vulnerability**. Or email Agent Router's security team at [envoy-ai-gateway-security@googlegroups.com](mailto:envoy-ai-gateway-security@googlegroups.com).

Include what an attacker could do, and steps to reproduce. We will reply to confirm we received it.

A wrong price or limit in a catalog is not a security problem. Open an issue or a pull request for it.
